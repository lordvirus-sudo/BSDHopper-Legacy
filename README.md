# 🐧 BSDHopper-Legacy

### Transform your old Android into a beautiful BSD-inspired desktop

## ✨ What is BSDHopper-Legacy?

**BSDHopper-Legacy** — це форк легендарного лаунчера **DistroHopper**, спеціально адаптований під старі версії Android(Використано версію 2.7.0).

Він повністю перетворює робочий стіл вашого пристрою на щось, що дуже нагадує класичний Linux-десктоп у стилі **Cinn.

Замість стандартної Android-оболонки ви отримуєте:
- Панель завдань 
- Меню додатків у стилі Linux?
- Чистий, мінімалістичний і атмосферний вигляд

Ідеально підходить для старих телефонів і планшетів, які хочеться «оживити» у стилі Unix-систем і зменшити навантаження.

---

## 🎯 Features

- 🖥️ **Повний Linux-подібний інтерфейс** на базі DistroHopper
- 🎨 **Тема в стилі BSD** (замість оригінальної Cinnamon)
- 📱 Підтримка **старих версій Android** (від 4.1+)
- ⚡ Легкий і швидкий навіть на слабких пристроях
- 🖼️ Налаштовувані іконки, шпалери та панелі
- 🗂️ Класичне меню додатків
- 🔧 Максимальна сумісність з legacy-пристроями

---

## 📥 Installation

1. Завантажте останній `.apk` з [Releases](../../releases)
2. Увімкніть «Встановлення з невідомих джерел»
3. Встановіть APK
4. Встановіть **BSDHopper-Legacy** як основний лаунчер
5. Насолоджуйтесь BSD-атмосферою ☕
